# PORTOFOLIO VENANDA PUTRI LESMANA

Website portofolio sederhana menggunakan:
- HTML
- CSS
- JavaScript
- Foto pertama = `assets/logo.jpg`
- Foto kedua = `assets/profil.jpg`

## Cara menjalankan di Acode
1. Ekstrak ZIP.
2. Buka folder `portfolio_ppl` di Acode.
3. Buka `index.html`.
4. Jalankan dengan preview/browser.

## Bagian yang perlu kamu ubah
Buka `index.html`, lalu ubah:
- `Nama Kamu`
- Username Instagram
- Nomor WhatsApp
- Email
- Judul dan isi project

Foto sudah dipasang sesuai permintaan:
- Foto pertama sebagai logo.
- Foto kedua sebagai foto profil.
